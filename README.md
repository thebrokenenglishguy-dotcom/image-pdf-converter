# ImageForge — Image & PDF Converter

A browser-based converter for JPG, PNG, WebP and HEIC/HEIF images.

## Current features
- Image → PDF
- JPG / PNG / WebP output
- HEIC / HEIF input
- Batch images → one PDF
- Resize by width/height
- Quality control and compression
- Drag-and-drop upload
- Client-side processing
- Experimental Adobe PageMaker P65 input

## Planned
- PDF → JPG/PNG
- PDF merge/split
- Image crop/rotate
- More PDF controls
